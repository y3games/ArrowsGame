# 화살표 탈출 미로 — 게임 개요 및 규칙

## 개념

화살표가 미로처럼 얽혀 있는 보드에서, 탈출 가능한(막히지 않은) 화살표를 찾아 클릭해 내보내는
퍼즐이다. 화살표는 자신이 가리키는 방향으로 보드 가장자리까지 다른 화살표가 하나도 없을 때만
탈출할 수 있다. 모든 화살표를 내보내면 보드를 클리어한 것이다.

이를 실시간 1:1 온라인 대전으로 만든다.

## 핵심 규칙

- **하트/목숨 없음.** 오직 시간으로만 승부한다.
- **시도(attempt)당 10초 제한.** 화살표 하나를 내보낼 때마다 10초의 시간 창이 주어진다.
  - 10초 안에 탈출 가능한 화살표를 클릭하면: 실제로 걸린 시간만큼만 누적 시간에 더해진다.
  - 막힌 화살표를 클릭하거나 10초 안에 아무것도 못 누르면: **그 즉시 남은 시간 동안 입력이
    막히는 강제 대기**에 들어간다. 즉, 실패한 시도는 항상 정확히 10초를 소모한다.
  - 이 규칙 덕분에 플레이어의 누적 시간 점수는 항상 실제 경과한 벽시계 시간과 정확히 같아진다
    — 그래서 "먼저 보드를 다 비운 사람"과 "시간이 더 짧은 사람"이 수학적으로 같은 기준이 되고,
    한 플레이어가 보드를 다 비우는 즉시 그 자리에서 라운드를 종료할 수 있다.
- **매치 구조: 3판 2선승제.** 라운드마다 새 보드를 무작위로 생성한다(두 플레이어는 같은 라운드
  안에서 항상 동일한 배치로 시작). 2승을 먼저 달성하는 쪽이 매치에서 승리한다.
- **1:1 대전.** 한 매치에 두 명이 참가하며, 상대방이 접속을 종료하면 즉시 남은 플레이어의
  승리로 매치가 종료된다.

## 기술 스택

- 클라이언트: Phaser 3 + Vite + TypeScript (`packages/client`)
- 서버: Node.js + Socket.IO + TypeScript (`packages/server`)
- 공유 로직: `packages/shared` — 보드 생성, 탈출 판정, 시도/라운드/매치 상태 전이를 모두 Phaser에
  의존하지 않는 순수 함수로 구현하고 클라이언트·서버가 그대로 import해서 쓴다.

## 서버 권위(authoritative) 설계

서버가 유일하게 신뢰되는 시계다. 클라이언트가 보내는 것은 `attempt:click` 하나뿐이고, 정답·오답·
거부 판정은 서버가 도착 시각을 기준으로 `@arrows/shared`의 `applyAttempt()`를 독립적으로 실행해
내린다. 클라이언트의 로컬 카운트다운/락 표시는 어디까지나 장식이며, 서버가 계산한 결과만 화면에
반영한다. 지연시간 보정 같은 고급 안티치트는 캐주얼 게임이라는 전제 하에 범위에서 제외했다.

## 보드 생성 알고리즘

무작위 탈출 순서를 먼저 정한 뒤, 그 **역순**으로 빈 보드에 화살표를 하나씩 배치한다. 매 배치마다
그 시점까지 놓인 화살표들을 기준으로 가장자리까지 경로가 완전히 비어 있는 칸+방향만 후보로 삼기
때문에, 완성된 보드는 항상 끝까지 풀 수 있음이 구성 과정 자체로 보장된다(휴리스틱이 아니라 증명
가능한 보장). 자세한 구현은 `packages/shared/src/game/board.ts` 참고.

## 검증 상태

- `packages/shared`: 보드 생성 가능성(여러 크기·시드), `applyAttempt`의 타임아웃/락 시간 계산,
  `currentWindowStart`(창 안·경계·여러 창 경과), 3판 2선승 상태 전이를 vitest로 자동 검증 (44개 테스트 통과).
- 서버(Socket.IO)를 소켓 클라이언트 2~3개로 직접 검증: 중복 `queue:join` 무시, 닉네임 12자 제한,
  `round:finished.remaining`, 매치 종료 뒤 상대가 나가도 결과가 다시 전송되지 않음, 같은 소켓의
  재대결 매칭, 대기 취소, 매치 중 접속 종료 시 승리 처리(1회), `/healthz`, 다중 CORS 출처.
- 브라우저(Chrome, 2~3개 탭)로 로비 → 닉네임 입력 → 대기/취소 → 매칭 → 3판 2선승 → 라운드별 요약
  → 새로고침 없는 "다시 하기" 재매칭, 10초 시간 초과 뒤 카운트다운 링 재충전, 서버 종료 시
  "서버 연결이 끊어졌습니다" 화면과 로비 복귀까지 end-to-end로 확인함.
- 배포 확인(2026-09-25): `https://y3games.github.io/ArrowsGame/`(GitHub Pages)과
  `https://arrows-game-server.onrender.com`(Render)로 브라우저 2개가 접속해 매칭되고, 한쪽이 나가면
  남은 쪽에 결과 화면이 뜨는 것까지 확인함. Render 프록시 때문에 접속 종료 감지가 약 10초 늦다.
- 아직 확인하지 못함: 배포 환경에서 3판 2선승을 끝까지 진행하는 것, 서버가 잠든 상태에서의 콜드 스타트
  안내 문구("서버를 깨우는 중…")의 실제 표시.
